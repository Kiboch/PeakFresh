Privacy Policy

Version 2026-10-22 · Based on inspected website code. Backend retention, operational access and provider settings require confirmation.

Information used

  • Account: email and password are submitted to Supabase Authentication; signup name is sent as display-name metadata. The account UI may read a profile name; the profiles table also has a phone field that may be used if a customer has provided it, and authorized order-management access may display it.
  • Orders: account identifier, selected size, quantity, pickup slot, order number, total, statuses and timestamps support ordering and order display.
  • Payment report: the signed-in customer can report their own order. The backend handles the report timestamp when available. This site does not collect an M-PESA PIN or confirmation code.
  • Support: phone and WhatsApp links open those services. This website does not receive the messages sent through them.
  • Location check: With your permission, the website requests your device location through browser geolocation. It sends the coordinates to Supabase to check whether your location is in an enabled Peak Fresh order region, before pickup times are shown and again when an order is submitted. Peak Fresh does not add your exact coordinates to your profile or order record. Location accuracy depends on your device and settings.

Purposes

Account data supports sign-in; order data supports order creation, pickup scheduling, payment-status display and management; device location is used to check whether ordering is available in the area before checkout; contact links let customers ask about accounts or orders.

Services and external links

The website sends account, order and location-check requests to the configured Supabase project. Exact device coordinates are sent to Supabase for the region check; map tiles are requested from OpenStreetMap around the displayed map area, which may reveal an approximate viewed area and normal request data such as your IP address to that provider. Leaflet is loaded from the unpkg CDN. Google sign-in is offered through Supabase OAuth when enabled; live provider configuration was not checked. The store map link opens Google Maps. WhatsApp opens only when selected. M-PESA payment is made outside this website. These providers may process data under their own terms. No analytics or advertising tag was found in the inspected site code.

Browser storage

Supabase maintains browser authentication state so sign-in can continue. This is essential to account and ordering features. The consent control stores a preference, version and timestamp in browser local storage. The code review found no optional analytics or marketing tags.

Retention and security

Account and order records are stored in the Supabase backend. Peak Fresh does not add the exact coordinates from a location check to the profile or order record; service-area names, centres and radii configured by an administrator are stored so the order check can run. Supabase may process request and operational data under its own terms. This review cannot confirm backend log retention, backups, provider region or operational access. No specific retention period or security guarantee is claimed; the project owner should confirm these settings.

Data requests

For access, correction, deletion or information requests, contact 0117543603 or WhatsApp. Peak Fresh may need to verify your identity and confirm what can be changed or removed.

Updates

This notice may change as the website or providers change. Contact Peak Fresh for the current version.
